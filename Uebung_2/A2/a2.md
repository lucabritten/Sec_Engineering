| Command | Beschreibung                              | Installationspfad      | Beispiel                              | Syscall               |
| ------- | ----------------------------------------- | ---------------------- | ------------------------------------- | --------------------- |
| rm      | Remove directory entries                  | /bin/rm                | rm -rf /                              | unlink()              |
| mv      | move files                                | /bin/mv                | mv file.txt tmp/file.txt              | ranameat2(), openat() |
| chmod   | change file modes or Access Control Lists | /bin/chmod             | chmod +x script.sh                    | fchmodat()            |
| chown   | change file owner and group               | /usr/sbin/chown        | chown nbel file.txt                   | fchownat()            |
| mkdir   | make directories                          | /bin/mkdir             | mkdir tmp                             | mkdirat()             |
| rmdir   | remove directories                        | /bin/rmdir             | rmdir                                 | unlinkat()            |
| kill    | terminate or signal a process             | shell built-in command | kill 1234                             | kill()                |
| ln      | link files                                | /bin/ln                | ln hard_link ex_file                  | linkat()              |
| sleep   | suspend execution for an interval of time | /bin/sleep             | sleep 5                               | clocknanosleep()      |
| wget    | The non-interactive network downloader    | /opt/homebrew/bin/wget | wget https://www.demo.de/download.txt | connect(), read()     |
